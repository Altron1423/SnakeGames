# Snake MMO

Многопользовательская (и однопользовательская) игра "Змейка", разработанная на языке Python с использованием библиотеки Pygame. Проект реализует надежную клиент-серверную архитектуру, поддерживающую как локальную одиночную игру, так и сетевые многопользовательские сессии с интеллектуальными противниками (ИИ).

## 🚀 Возможности

* **Поддержка мультиплеера**: Подключайтесь к игровым серверам, чтобы соревноваться с другими игроками в синхронизированном окружении.
* **Одиночный режим**: Создавайте собственный локальный сервер для игры в одиночку или тренировки механик.
* **Змейки с ИИ**: Динамичные противники, которые реагируют на состояние игрового мира.
* **Продвинутая сеть**: Кастомный протокол связи на базе сокетов с сериализацией данных через DTO (Объекты передачи данных).
* **Динамическая конфигурация**: Игровые сущности, карты и настройки загружаются из JSON-конфигурационных файлов.
* **Система сохранений**: Управление состоянием игры и прогрессом игрока с помощью файлов сохранений.
* **Динамический интерфейс**: Модульная система пользовательского интерфейса на базе Pygame.

## 🛠️ Предварительные требования

* **Python 3.8+**
* **pip** (менеджер пакетов Python)

## ⚙️ Установка

1. **Клонируйте репозиторий:**
   ```bash
   git clone <repository-url>
   cd SnakeGames
   ```

2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

## 🎮 Как играть

### Одиночная игра (Локальный хост)
1. Запустите приложение: `python MMO.py`
2. Выберите **"Одиночная игра"** в главном меню.
3. Выберите файл сохранения, чтобы начать игру.
4. Создать файл сохранения можно запустив `python testing_create_world.py` (WIP)

### Мультиплеер
1. **Запуск сервера:**
   - Мир запущенный в одиночной игре уже считается локальным хостом, доступным для подключения. (WIP)
2. **Подключение к серверу:**
   - Запустите `python MMO.py` на втором экземпляре (или на другом компьютере в той же сети).
   - Выберите **"Многопользовательская игра"**.
   - Клиент просканирует сеть на наличие доступных серверов. Выберите нужный сервер для подключения.

## 📁 Структура проекта

```text
SnakeGames/
├── MMO.py                          # Точка входа в приложение
├── requirements.txt                # Зависимости проекта
├── docs/                           # Подробная документация
├── libs/                           # Основные библиотеки модулей
│   ├── animation_controller/       # Контроллеры анимации
│   ├── conecting/                  # Сетевой уровень (логика клиента и сервера)
│   ├── dtos/                       # Объекты передачи данных (DTO)
│   ├── file_works/                 # Расширенное взаимодействие с файлами
│   ├── game/                       # Основная игровая логика (движки сервера и клиента)
│   ├── generators/                 # Процедурные генераторы
│   ├── graphics/                   # Рендеринг, окно и интерфейс
│   ├── loaders/                    # Загрузчики данных (карты, сущности, анимации)
│   ├── mappers/                    # Мапперы (преобразование DTO <-> Dict)
│   ├── math/                       # Математические утилиты (векторы, позиции)
│   ├── save/                       # Работа с игровыми сохранениями
│   ├── windows/                    # Системные представления интерфейса
│   ├── application.py              # Основа приложения
│   ├── Core.py                     # Подгрузка системной информации
│   ├── Loger.py                    # Логирование данных
│   ├── ticker.py                   # Счётчик тактов
│   └── version.py                  # Отслеживание версий
├── src/                            # Исходные данные и модули
│   ├── data/                       # Статические игровые данные (JSON, изображения, карты)
│   └── modules/                    # Высокоуровневые игровые модули
└── testing_*.py                    # Скрипты тестирования и клиенты
```

## 🛠️ Используемые технологии

* **Python**: Основной язык программирования.
* **Pygame**: Используется для графики, обработки ввода и основного игрового цикла.
* **Sockets**: Для низкоуровневой сетевой связи.
* **JSON**: Для хранения и конфигурации данных.
