# Справочник API

В данном документе приведен справочник по основным классам и методам, используемым в проекте Snake MMO.

## 🚀 Основное приложение

### `App` (в `MMO.py`)
Наследуется от `Application`. Центральная точка входа в игру.

* **`run()`**: Основной цикл выполнения. Управляет жизненным циклом приложения, обработкой событий и рендерингом.
* **`exit(reason=None)`**: Безопасное завершение работы приложения.
* **`add_functions(dict_functions)`**: Регистрирует функции, которые могут быть вызваны через события/UI.
* **`give_function(data, passw=None)`**: Безопасно извлекает зарегистрированную функцию.

## 🎮 Игровой движок

### `GameServer` (в `libs/game/game_server.py`)
Авторитетный движок, работающий на стороне сервера.

* **`set_game_data(save_full, get_user_action, send_to_user, player_name)`**: Инициализирует сервер с состоянием сохранения и механизмами связи.
* **`summon_new_player(name)`**: Создает и добавляет нового игрока в игровой мир.
* **`player_connect(name)`**: Обрабатывает подключение игрока.
* **`player_disconnect(name)`**: Обрабатывает отключение игрока.
* **`main()`**: Основной игровой цикл сервера. Обрабатывает действия игроков и рассылает обновления.
* **`saving()`**: Сохраняет текущее состояние игры в файл.

### `GameClient` (в `libs/game/game_client.py`)
Движок, работающий на стороне клиента.

* **`set_game_data(get_data_from_server, send_game_data, window)`**: Инициализирует клиент с сетевыми и рендеринг-функциями.
* **`moving_to(direction)`**: Обновляет направление движения локального игрока.
* **`draw()`**: Отрисовывает игровой мир и камеру на экране.
* **`update_entities(entities)`**: Синхронизирует состояние локальных сущностей с данными, полученными от сервера.
* **`main()`**: Основной игровой цикл клиента. Обрабатывает ввод, отправляет действия и обрабатывает входящие данные от сервера.

## 🌐 Сетевой уровень

### `ServerConnector` (в `libs/conecting/server.py`)
Управляет входящими TCP-соединениями и распределяет сообщения игровой логике.

* **`start_server()`**: Открывает основной сокет и начинает прослушивание подключений.
* **`main(tick)`**: Обрабатывает входящие сетевые сообщения и направляет их соответствующим пользователям.
* **`send_to_user(dto, user_name)`**: Отправляет сообщение конкретному подключенному игроку.
* **`get_user_action()`**: Генератор, который выдает действия, отправленные игроками.
* **`send_game_data(dto)`**: Отправляет данные из локального приложения на сервер (используется при локальном хостинге).

### `ClientConnector` (в `libs/conecting/client.py`)
Управляет соединением клиента с удаленным сервером.

* **`start_client()`**: Инициализирует сокет.
* **`connect(address)`**: Подключается к указанному IP и порту.
* **`join_game()`**: Отправляет запрос на вступление в игру серверу.
* **`find_servers()`**: Сканирует сеть на наличие доступных игровых серверов.
* **`send_game_data(dto)`**: Отправляет игровые данные (действия игрока) на сервер.
* **`get_data_from_server()`**: Генератор, выдающий данные, полученные от сервера.

## 📦 Объекты передачи данных (DTO)

DTO используются для определения фиксированного контракта сетевых сообщений.

* **`ConnectClientDTO`**: Используется для процесса рукопожатия (handshake) при подключении.
* **`ConnectServerDTO`**: Используется серверами для анонса своего присутствия.
* **`GameDataToClientDTO`**: Полезная нагрузка, отправляемая от сервера к клиенту, содержащая состояние игрового мира.
* **`GameDataToServerDTO`**: Полезная нагрузка, отправляемая от клиента к серверу, содержащая действия/ввод игрока.
